How "missed" is decided same in all three

Per week: planned days so far vs days you actually trained so far. If you're short, only that many planned-but-empty days get the outline, newest first. Training on a rest day makes up for a missed one.

Today is never marked missed (the day isn't over), and nothing before the plan's start date is judged. Without a training plan there are no outlines at all.
