Exercise analytics chart — three designs

Same made-up history for Incline Dumbbell Bicep Curl over 3 months (with a two-week break in September). Dots are spaced by date, so gaps show as gaps. Grid lines every 2.5 kg, dates as day/month, range chips stay as they are.

AClean line

One line through each session's heaviest set, with a soft fade underneath. Nothing else on the chart — the simplest switch from bars.

BLine + PRs + tap

Same line, but sessions that set a new record get a bigger solid dot. Tapping a dot shows that session (here 14/10 is tapped). Adds an "Est. 1RM" chip next to Heaviest set and Volume. The headline shows the latest number and change over the range. My pick.

CLine for weight, bars for volume

Heaviest set (and Est. 1RM) as a line; Volume stays as bars, since volume naturally jumps around and a zig-zag line can look like going backwards. Both shown here as you'd see them switching chips.
